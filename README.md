# Fibonacci Number Generator

A simple **Fibonacci Number Generator** built using Python.
This beginner-friendly project generates the Fibonacci sequence for 
the number of terms entered by the user.

## Features

- Accepts the number of terms from the user
- Generates the Fibonacci sequence
- Displays the numbers in sequence
- Simple and beginner-friendly

## Technologies Used

- Python
- `for` loop
- Variables
- User input
- Arithmetic operators
- Multiple assignment

## Concepts Learned

- Fibonacci sequence
- Basic Python logic
