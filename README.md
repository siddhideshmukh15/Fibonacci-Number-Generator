
# Fibonacci Number Generator

## Description
Fibonacci Number Generator is a beginner-friendly Python project that generates a Fibonacci series for a specified number of terms. It also calculates the sum of the series and allows users to generate multiple series.

## Features
- Generates the Fibonacci series.
- Accepts the number of terms from the user.
- Calculates the sum of the generated series.
- Allows users to generate multiple series.
- Validates user input.
- Handles invalid and non-positive inputs.

## Technologies Used
- Python 3
- Visual Studio Code (VS Code)

## Concepts Learned
- Variables and data types
- `input()` and `print()`
- `for` and `while` loops
- Conditional statements (`if`, `continue`, `break`)
- Multiple variable assignment
- String validation using `isdigit()`
- Calculating totals using an accumulator

## Future Improvements
- Generate Fibonacci numbers up to a specified limit.
- Display the largest number in the series.
- Save generated series to a text file.
- Add a graphical user interface (GUI).
